Connect your calendar

  1. Open Settings → Connectors in your AI app (ChatGPT calls them Apps).
  2. Pick your calendar, Google or Outlook, and allow read-only.
  3. Ask: “What’s on my Friday?”

Skills

Build slides like I did

talk-deck makes the deck you saw: one HTML file, no software to buy. You tell an AI agent what the talk is about. It asks which visual style to use, draws the pictures, checks every slide, and hands you a file you can open, present or share.

  1. Download talk-deck and add it to your AI agent. talk-deck.zip · 46 KB
    It runs scripts, so it works best in an agent that can run code: Claude Code, Codex, or Claude with code execution.
  2. Give it your script. Paste it in and say:
    Turn this script into slides with talk-deck.
  3. Choose your visual language. Before it draws anything, the agent shows you a preview of each style and asks which analogy the pictures should use. You pick one, and every picture follows it, so the deck looks like one idea:

    Or choose plain (no analogy), or describe your own: a football team, an orchestra, a road trip. The agent draws it.

    How to pick an analogy: a Lego example
    1. List the big ideas in your talk: the parts that fit together, the levels you climb, a gate or boundary, the steps, the before and after.
    2. Ask what your audience already knows. Lego works for almost everyone. A kitchen suits a team of cooks.
    3. Check every idea has an object. If you can’t name the object for “levels” or “gate”, it is the wrong analogy.
    4. Preview it, then decide once. Keep one colour for each idea, on every slide.

    Lego, worked out. Say the talk explains how an AI agent is built:

    Idea in the talkLego object
    A model on its own, doing nothing yetThe green baseplate
    Knowledge, tools, skillsA red, a blue and a yellow brick that click on
    Three levels, each a step upBricks that rise like steps
    A company with one way inA room with one door
    Something the audience adds themselvesAn empty dashed brick: “your turn”

    One rule: never mix analogies. If a bricks slide is followed by a tree, the audience has to learn the picture again.

  4. Ask it to check. The agent can take a screenshot of every slide, so it sees what the audience sees:
    Take a screenshot of every slide and fix anything that overflows or looks crowded.
  5. Share a safe copy. Speaker notes hide inside a deck’s page source. Ask for a copy without them:
    Build a share copy of the deck with no speaker notes and no video slides.

Add a skill to your AI tool

Claude

  1. Settings → Capabilities: turn on code execution and file creation.
  2. Go to Customize → Skills and upload the skill’s .zip.
  3. Toggle it on, then ask for it by name.

Claude Code: copy the skill’s folder into ~/.claude/skills/ (all projects) or .claude/skills/ (one project).

Official guide ↗

ChatGPT

  1. In the sidebar, open Plugins → Skills.
  2. Choose Create → Upload from your computer.
  3. ChatGPT scans the skill, then you install it.

Availability depends on your plan. Skills are added per device, so repeat on web and desktop.

Official guide ↗

Gemini

  1. Open the Skills page in the Gemini app on Mac, or on gemini.google.com.
  2. Import the skill by uploading its SKILL.md file.
  3. Type / in a chat to use it.

Uploading files is available on the Mac app and the web app.

Official guide ↗

Any other AI

A skill is just a markdown file of instructions. Paste the contents of SKILL.md into the tool’s custom instructions, or into a project, and ask for it by name.

That works everywhere, but it does not run a skill’s scripts. For talk-deck, use an agent that can run code.
